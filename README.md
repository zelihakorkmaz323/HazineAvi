# 🎮 Hazine Avı

Python ve Pygame kullanılarak geliştirilmiş basit bir 2D hazine bulma oyunudur.

## 🕹️ Oyun Nasıl Oynanır?

Oyuncu mavi kareyi yön tuşlarıyla hareket ettirir.

Amaç, yeşil duvarlara takılmadan sarı hazineye ulaşmaktır.

Hazineye ulaşıldığında oyuncu kazanır ve ekranda:

**"Hazineyi Buldun!"**

mesajı gösterilir.

## ⌨️ Kontroller

- ⬆️ Yukarı ok → Yukarı hareket
- ⬇️ Aşağı ok → Aşağı hareket
- ⬅️ Sol ok → Sola hareket
- ➡️ Sağ ok → Sağa hareket
- R → Oyunu yeniden başlat
- ESC → Oyundan çık

## 🛠️ Kullanılan Teknolojiler

- Python 3.9
- Pygame 2.6.1
